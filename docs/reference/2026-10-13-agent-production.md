## 公网真实验收

使用服务器通过公网 HTTPS 创建独立访客会话，并上传合成附件；
没有使用用户私人资料。模型为供应商配置的 `deepseek-flash`，用量均由供应商
实际返回。各项通过后还验证同键提交不会再调用模型。

| 场景 | 验收结果 | 模型调用 | 耗时 |
| --- | --- | ---: | ---: |
| 文本 | 精确返回本次随机验收码，无推理内容混入 | 1 | 4.3 秒 |
| 文件 RAG | 正确读取随机文件验收码，并引用原文 | 1 | 12.1 秒 |
| 双文件 Agent | 自主调用两个读取工具，正确对比地区、日期和随机验收码，引用两份文件 | 3 | 24.5 秒 |
| 图片与文件 | 识别问题中未透露的图片码 VISION-7294，同时回答文件随机码并正确区分来源 | 1 | 27.9 秒 |

四项均通过：SSE 首页后主动断开、按最后序号重连、流内容与持久答案一致、
同幂等键回放、终态游标回放。图片与文件回答仅使用一次视觉模型调用。
合成文件在验收后删除。公网 HTML 与 9 个引用资源逐字节匹配发布目录。
原来的 owner-only 无付费回放检查因无历史任务跳过；以上真实访客任务已经
独立覆盖公网 SSE 回放，不把该跳过项算作通过。

## 实测修复

首次候选验收发现原 SSE 解析器把 `reasoning_content` 当成答案，
且真实模型的长推理会消耗有限工具决策预算。未将失败候选切换上线。

最终版删除推理到答案的后备映射，仍正确记录用量；在小请求验证供应商支持
`thinking: { type: "disabled" }` 后，启用 `AGENT_DISABLE_THINKING=true`。
该选项只作用于资料研究，普通聊天与图文设置不变。发布脚本逐项验证其余配置
未改变，保留 root-owned 0600 权限，任何发布失败会恢复旧配置和旧代码。
