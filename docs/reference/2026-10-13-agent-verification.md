## 浏览器结果

独立本地预览：前端 `http://127.0.0.1:5179`，模拟后端端口 3213。
使用浏览器 DevTools 与合成资料验收，未操作线上聊天。

- 390 × 844 手机视口：上传、资料研究开关、发送、原文展开、完成步骤回看正常。
- 1440 × 900 桌面视口：来源引用、搜索/读取步骤、用量展示正常。
- 两种视口均未出现横向溢出；展开的步骤区有独立高度限制与滚动。
- Agent 一次任务显示 3 次模型调用；文件和图片共同输入显示 1 次视觉模型调用。
- 上传后 `POST /tasks` 返回 202，任务 SSE 观察与最终快照返回 200。
- 控制台出现的上传状态 404 是首次上传的“无历史分片”检查，之后上传成功；
  未观察到该流程的 JavaScript 运行异常。
