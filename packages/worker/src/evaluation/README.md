# 离线原文证据评测 v1

此目录包含 30 道固定、原创合成资料测试：10 道单文件事实检索、6 道多文件比较、5 道无依据、4 道长文/预算/概览、5 道引用格式与隔离测试。

执行：`pnpm --filter @ai-tool-chat/worker exec vitest run src/evaluation src/retrieval/evidence.test.ts`

可选保存 JSON：先设置 `EVIDENCE_EVAL_REPORT` 为新的绝对输出文件路径，再执行上述命令。文件采用独占创建，不覆盖旧报告。测试本身不会调用网络或收费模型，也不包含用户资料。

报告的耗时是本机索引/检索耗时，token 是检索文本估算值，费用是 unknown；不将这些数字当成线上模型延迟或实际账单。30/30 通过仅代表这些检索/证据格式案例通过，不等于生成回答正确率 100%。引用格式正确也不证明原文语义支持结论。

另有独立固定种子随机 Unicode/CRLF 边界测试验证原文偏移、行号和切片，不用固定问题的措辞校准检索算法。未来获准运行真实模型评测时，应另存 provider/model/prompt 版本、实际 usage、延迟、人工语义支持评分，不能替换此离线口径。
